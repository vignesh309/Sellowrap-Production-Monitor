This is the code to run in the JP's computer or server to completetly change the name of part_master table to
rm_master in order to make our new code work.

-- 1. Rename the table itself
ALTER TABLE IF EXISTS public.part_master RENAME TO rm_master;

-- 2. Rename the Primary Key
ALTER INDEX IF EXISTS part_master_pkey RENAME TO rm_master_pkey;

-- 3. Rename the Unique Constraint on part_no
ALTER TABLE IF EXISTS public.rm_master RENAME CONSTRAINT part_master_part_no_key TO rm_master_part_no_key;

-- 4. Rename the custom Index you created
ALTER INDEX IF EXISTS ix_part_master_id RENAME TO ix_rm_master_id;

-- 5. Rename the Auto-Increment Sequence for the ID
ALTER SEQUENCE IF EXISTS part_master_id_seq RENAME TO rm_master_id_seq;

Checklist for deploying in ADS System

1. Copy paste the entire project files with Frontend and Backend.
2. Change the Logo in the img folder of Frontend.
3. Change the .env files according to the database name and password
4. In the .env file paste the correct telegram bot token and chat ID
5. In the telegram_notifier.py file need to update the cloudflare id message
6. After installation of the postgresql and pgadmin need to add a line in the pg_hba.conf
file which will be normally in the location "C:\Program Files\PostgreSQL\18\data\pg_hba.conf".
This line should be added below the field where "# IPv4 local connections:" is present.
host    all             all             0.0.0.0/0               scram-sha-256
7. In the postgresql.conf file make sure this line is present "listen_addresses = '*'"
under the #-Connection Settings - field so that any device can communicate with database.
8. Download mosquito broker service from the internet and install it.
9. After installation of mosquito broker get to the location "C:\Program Files\Mosquitto" 
and open the mosquitto.conf file inside that paste the lines just below this "#include_dir"
line. 
listener 1883 0.0.0.0
allow_anonymous true
persistence true
persistence_file mosquitto.db
so that mosquito will listen in port 1883 for machine trigger counts.

** GITHUB Commands **

Run this two commands to one by one to ignore .env or any specific files to ignore from pushing to repository

Remove the .env file from Git's tracking memory

git rm --cached Backend/.env

Create a .gitignore file and add the .env path to it so Git ignores it forever

echo Backend/.env >> .gitignore

Run this commands one by one:
git add .gitignore
git commit -m "Security Update: Remove and ignore .env file"
git push origin main

To force pull the code from repository:

git fetch --all
git reset --hard origin/main
git pull origin main
